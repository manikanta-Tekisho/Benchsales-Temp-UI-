# TEKISHO Bench Sales UI

React + Vite static mock application implementing the formal Type 2 Bench Sales screens from the supplied UI deck.

## Run
```
npm install
npm run dev
```

## Production build
```
npm run build
```

## Screens
- Dashboard
- JD Register
- JD Detail / Matched Consultants
- Consultant Bench Inventory
- Skill Coverage
- Consent Requests
- Vendor Submissions

All screens use local demo data and client-side navigation.
